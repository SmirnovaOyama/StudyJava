# Course 2 Exercises

## Exercise 1: Grade Evaluator
**Difficulty: Easy**

Write a program that takes a score (0-100) and displays the grade:
- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: Below 60

## Exercise 2: Day of the Week
**Difficulty: Easy**

Using a switch statement, write a program that takes a number (1-7) and displays the corresponding day of the week.

## Exercise 3: Multiplication Table
**Difficulty: Medium**

Write a program that displays the multiplication table for a given number from 1 to 10.

## Exercise 4: Number Guessing Game
**Difficulty: Medium**

Create a simple number guessing game where:
- The program picks a number between 1 and 100
- The user guesses the number
- The program gives hints (too high/too low)
- Continue until the user guesses correctly

## Exercise 5: Prime Number Checker
**Difficulty: Hard**

Write a program that checks if a given number is prime.

## Bonus: Print All Prime Numbers
**Difficulty: Hard**

Write a program that prints all prime numbers between 1 and 100.
