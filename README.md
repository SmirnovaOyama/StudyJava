# StudyJava - Comprehensive Java Learning Path

Welcome to your complete Java learning journey! This repository contains 8 comprehensive courses designed to take you from beginner to advanced Java developer.

## 📚 Course Structure

### [Course 1: Java Basics](./Course1-JavaBasics/)
Learn the fundamentals of Java programming including:
- Setting up Java development environment
- Your first Java program (Hello World)
- Variables and Data Types
- Operators and Expressions
- Input/Output basics

### [Course 2: Control Flow](./Course2-ControlFlow/)
Master program flow control:
- If-else statements
- Switch statements
- For loops
- While and Do-While loops
- Break and Continue statements

### [Course 3: Object-Oriented Programming](./Course3-OOP/)
Understand OOP principles:
- Classes and Objects
- Constructors
- Inheritance
- Polymorphism
- Encapsulation
- Abstract classes and Interfaces

### [Course 4: Java Collections Framework](./Course4-Collections/)
Work with data structures:
- ArrayList and LinkedList
- HashSet and TreeSet
- HashMap and TreeMap
- Queue and Stack
- Iterator and for-each loop

### [Course 5: Exception Handling](./Course5-Exceptions/)
Handle errors gracefully:
- Try-catch blocks
- Multiple catch blocks
- Finally block
- Throw and Throws
- Custom exceptions

### [Course 6: File I/O and Streams](./Course6-FileIO/)
Master file operations:
- Reading and Writing files
- BufferedReader and BufferedWriter
- File class operations
- Serialization
- Java NIO basics

### [Course 7: Multithreading and Concurrency](./Course7-Multithreading/)
Learn concurrent programming:
- Creating threads
- Thread lifecycle
- Synchronization
- Thread pools
- Concurrent collections

### [Course 8: Advanced Topics](./Course8-Advanced/)
Explore modern Java features:
- Generics
- Lambda Expressions
- Functional Interfaces
- Stream API
- Optional class
- Method References

## 🚀 Getting Started

1. Clone this repository
2. Start with Course 1 and progress sequentially
3. Complete the exercises in each course
4. Practice with the example code
5. Build your own projects using what you've learned

## 📖 How to Use This Repository

Each course folder contains:
- **README.md**: Course overview and concepts
- **Examples/**: Working code examples
- **Exercises/**: Practice problems with solutions
- **Projects/**: Mini-projects to apply your knowledge

## 🎯 Prerequisites

- Install Java JDK (version 11 or higher recommended)
- A text editor or IDE (VS Code, IntelliJ IDEA, Eclipse, or NetBeans)
- Basic computer literacy

## 💡 Learning Tips

1. Don't rush - take your time to understand each concept
2. Type out the code examples yourself (don't just copy-paste)
3. Experiment with the code - try modifying examples
4. Complete all exercises before moving to the next course
5. Build small projects to reinforce your learning
