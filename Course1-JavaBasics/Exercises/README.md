# Course 1 Exercises

Complete the following exercises to practice what you've learned in Course 1.

**How to use:** Each exercise has a starter file (Exercise1.java, Exercise2.java, etc.) with TODO comments to guide you. Try to complete the exercises on your own before checking the solutions in the `Solutions/` folder.

## Exercise 1: Personal Introduction
**Difficulty: Easy**

Write a program that prints your name, age, and favorite hobby.

**Expected Output:**
```
My name is [Your Name]
I am [Your Age] years old
My favorite hobby is [Your Hobby]
```

## Exercise 2: Rectangle Area Calculator
**Difficulty: Easy**

Write a program that calculates and displays the area of a rectangle. Use variables for length and width.

**Formula:** Area = length × width

**Example:**
- Length: 5
- Width: 3
- Area: 15

## Exercise 3: Temperature Converter
**Difficulty: Medium**

Write a program that converts temperature from Celsius to Fahrenheit.

**Formula:** Fahrenheit = (Celsius × 9/5) + 32

**Example:**
- Celsius: 25
- Fahrenheit: 77.0

## Exercise 4: Simple Interest Calculator
**Difficulty: Medium**

Write a program that calculates simple interest.

**Formula:** Simple Interest = (Principal × Rate × Time) / 100

**Example:**
- Principal: 1000
- Rate: 5
- Time: 2 years
- Simple Interest: 100

## Exercise 5: Swap Two Numbers
**Difficulty: Medium**

Write a program that swaps the values of two variables without using a third variable.

**Example:**
- Before swap: a = 10, b = 20
- After swap: a = 20, b = 10

**Hint:** Use arithmetic operations to swap values

## Bonus Exercise: BMI Calculator
**Difficulty: Hard**

Write a program that:
1. Asks the user for their weight (in kg) and height (in meters)
2. Calculates their BMI (Body Mass Index)
3. Displays the result

**Formula:** BMI = weight / (height × height)
